# Vehicle-Insurance-Excel-Dashboard
The Vehicle Insurance Analysis project focuses on analyzing customer and vehicle insurance data to understand customer characteristics, policy-related patterns, and insurance response behavior. The project was developed using Microsoft Excel and demonstrates practical data analysis and reporting skills.

The raw dataset was cleaned and organized before performing the analysis. Excel formulas, filtering, sorting, Pivot Tables, and data summarization techniques were used to prepare the data and identify relevant patterns.

The analysis examines customer demographics, vehicle-related information, insurance-related attributes, and customer responses. Different categories and customer segments were compared to understand patterns in insurance interest and response behavior.

Pivot Tables and charts were used to summarize the findings and present important trends in an easy-to-understand format. An Excel-based dashboard was created to provide a clear overview of the analysis and support quick interpretation of the results.

The project demonstrates the practical application of Excel for data cleaning, exploratory analysis, reporting, visualization, and business insight generation. It also highlights the ability to work with structured customer data and convert raw information into useful insights for business decision-making.

**Tools & Skills:** Microsoft Excel, Data Cleaning, Excel Formulas, Pivot Tables, Data Analysis, Data Visualization, Dashboard Development, Customer Analysis, Business Insights.
